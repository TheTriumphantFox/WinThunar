A fast, familiar, keyboard-friendly file manager with tabs, split panes, bulk rename, undo/redo and plugins. Free and open source.

What you get

The layout and habits of Thunar, on top of native Windows APIs.

Tabs and split panes

Ctrl+T opens a tab with its own history. F3 splits the window and file commands follow the active pane.

File jobs you can trust

Copies are staged at the destination and replacements roll back on failure, so an interrupted transfer cannot destroy the file you already had. Interrupted jobs are recovered on restart.

Undo and redo

Ten levels for create, rename, copy, move, and duplicate, with checks that the destination still matches before anything is reversed.

Transfer queue

Byte progress, throughput, ETA, queued-job count, and cancel for the active job.

Search and bulk rename

Ctrl+F searches subfolders with live results. Bulk rename previews every change, avoids collisions, and undoes as one step.

Thunar-style drag and drop

Move on the same volume, copy across volumes. Ctrl forces copy and Shift forces move.

Built-in terminal panel

F4 opens PowerShell that follows the folder you are browsing.

Plugins in plain JSON

Add custom actions with file patterns and confirmation prompts. Bundled plugins cover archives, Git status/diff/log, media tags, and sharing.

Windows-native

Shell icons and thumbnails, the Recycle Bin, NTFS alternate data streams, network shares, Properties, Open With, and the full Explorer context menu.

Use it as your default file manager

Optional, reversible, and limited to your own account.

Edit > Preferences > Windows Integration adds "Open in WinThunar" to Explorer's folder menu and can make WinThunar the handler for opening folders and drives. Changes are written only to HKCU, remember what they replaced, and are undone when you turn the setting off. If WinThunar ever fails to start, WinThunar.exe --unregister-shell restores everything.

Install

Pick whichever suits you.

  • Installer (recommended). Download the .msi from the latest release. Choose "Just me" (no administrator permission) or "Everyone", and which shortcuts to create. Installed copies update themselves in the background.
  • Portable. Download the portable ZIP, extract it anywhere, and run WinThunar.exe.
  • Build from source. You need Windows 11 and the .NET 10 SDK: 
    dotnet restore .\WinThunar.csproj -r win-x64
dotnet build .\WinThunar.csproj --configuration Debug -p:Platform=x64 --no-restore
dotnet run --project .\WinThunar.csproj --configuration Debug -p:Platform=x64
